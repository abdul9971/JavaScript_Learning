<h1 align="center">📘 JavaScript Learning Repository</h1>

<p align="center">
This repository contains my practice code and projects while learning 
<strong>JavaScript fundamentals and advanced concepts</strong>.  
It showcases topics ranging from <em>DOM manipulation</em> to <em>asynchronous programming</em> and <em>API integration</em>.
</p>

<hr/>

<h2>🗂️ Topics Covered</h2>
<ol>
  <li><strong>DOM Manipulation</strong> – Selecting elements with <code>querySelector</code>, changing styles dynamically</li>
  <li><strong>Timers</strong> – Using <code>setTimeout</code> for delayed execution</li>
  <li><strong>Callback Functions</strong> – Nested callbacks (callback hell example)</li>
  <li><strong>Loops</strong> – Iterating arrays with <code>for...of</code></li>
  <li><strong>Promises</strong> – Creating promises with <code>resolve</code> and <code>reject</code></li>
  <li><strong>Promise Chaining</strong> – Sequential async operations using <code>.then()</code> and <code>.catch()</code></li>
  <li><strong>Async/Await</strong> – Cleaner asynchronous code with <code>async</code> functions</li>
  <li><strong>Error Handling</strong> – Using <code>try...catch</code> with async/await</li>
  <li><strong>API Calls</strong> – Fetching data with <code>fetch</code> and <code>axios</code></li>
  <li><strong>Event Listeners</strong> – Handling button clicks with <code>addEventListener</code></li>
  <li><strong>Conditional Rendering</strong> – Displaying images vs videos based on file type</li>
  <li><strong>Working with External APIs</strong>:
    <ul>
      <li>Cat Facts API (<a href="https://catfact.ninja/">catfact.ninja</a>)</li>
      <li>Random Dog API (<a href="https://random.dog/">random.dog</a>)</li>
      <li>Dad Jokes API (<a href="https://icanhazdadjoke.com/">icanhazdadjoke.com</a>)</li>
      <li>Universities API (<a href="http://universities.hipolabs.com/">hipolabs.com</a>)</li>
    </ul>
  </li>
  <li><strong>Form Input Validation</strong> – Ensuring valid input before API calls</li>
  <li><strong>Dynamic DOM Updates</strong> – Creating and appending <code>&lt;li&gt;</code> elements dynamically</li>
  <li><strong>Closures</strong> – Maintaining private variables</li>
  <li><strong>Constructor Functions</strong> – Creating objects with constructor functions</li>
</ol>
